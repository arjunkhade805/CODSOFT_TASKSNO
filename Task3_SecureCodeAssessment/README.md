# Task 3 - Secure Code Assessment

## Objective
- Choose an application developed in a programming language of your choice.
- Examine the source code to identify common security weaknesses and coding flaws.
- Use static code analysis tools or perform a manual security review.
- Suggest secure coding practices to improve the application's security.
- Prepare a report documenting vulnerabilities and recommended fixes.

## Application Assessed
A sample Flask-based Python web application (`vulnerable_app.py`), intentionally written with common security flaws for educational assessment purposes.

## Method Used
Manual source code review, supported by reference to the OWASP Top 10 vulnerability list.

## Findings
See [Security_Assessment_Report.md](./Security_Assessment_Report.md) for full details on vulnerabilities found and recommended fixes.

## Learning Outcome
This task helped in understanding how common vulnerabilities like SQL Injection, XSS, Command Injection, and Path Traversal occur in real code, and how to identify and fix them using secure coding practices.
